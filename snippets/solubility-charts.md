### Chart I — Soluble chart

Compounds with these ions **are soluble**, except when paired with an ion in the *Except* column.

<div class="mnemonic" markdown>

**Mnemonic:** *"No Cheating, Bullying, Intimidating Students"*

| | Soluble | Except |
|---|---|---|
| NO | $\ce{(NO3)-}$, $\ce{(NH4)+}$ | — |
| CH | $\ce{(CH3COO)-}$ | — |
| B, I, Cl | $\ce{Br-}$, $\ce{I-}$, $\ce{Cl-}$ | $\ce{Ag+}$, $\ce{Pb^2+}$, $\ce{Hg2^2+}$ |
| So | $\ce{(SO4)^2-}$ | Heavy metal ions, $\ce{Pb^2+}$, $\ce{Hg2^2+}$, $\ce{Ag+}$ |

</div>

All ionic compounds with these polyatomic ions are soluble.

### Chart II — Insoluble chart

Compounds with these ions **are insoluble**, except when paired with an ion in the *Except* column.

<div class="mnemonic" markdown>

**Mnemonic:** *"Smoking Counterproductive Zero"*

| | Insoluble | Except |
|---|---|---|
| S | $\ce{S^2-}$ | Group 1A, $\ce{(NH4)+}$, Heavy metal |
| CO | $\ce{(CO3)^2-}$ | Group 1A, $\ce{(NH4)+}$ |
| PO | $\ce{(PO4)^3-}$ | Group 1A, $\ce{(NH4)+}$ |
| O | $\ce{(OH)-}$ | Group 1A, $\ce{(NH4)+}$, Heavy metal |

</div>

**Heavy metal ions**
:   $\ce{Ca^2+}$, $\ce{Sr^2+}$, $\ce{Ba^2+}$
